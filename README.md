# New-Venture-to-Liyandra
Venture to Liyandra (Pre-alpha and so on).

-Initially created under the ideas and concepts of Vaeloridas and his help, after a long time stagnated and stopped for different reasons I decided, with his permission, to continue the project by mixing it with another project that had been left up in the air, "India mod; Blossom Islands".
This mod is intended to be quite extensive and is currently under development.


The team includes:

-Vaeloridas, Panther, Satanoy, and the India Mod team (Dinodude, Fridmhyr, and Arithon).


Ultimately, if everything goes well, this could serve as a gateway to another mod based on India.
